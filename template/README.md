# NumPy 100 Exercises — Template

Copy this folder to start practicing on your own.

## Setup

```bash
pip install numpy
```

## Run

```bash
python main.py
```

## How to use

1. Open `tasks.py`
2. Find a task and replace `pass` with your solution
3. Run `python main.py` to see the output
4. Set `skip=True` on completed tasks to hide them from future runs

## Files

- `tasks.py` — all 100 exercises as empty stubs
- `decorators.py` — task runner helpers (no need to edit)
- `main.py` — runs all tasks
